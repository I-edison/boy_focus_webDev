# Focus — Portfolio

A responsive, single-page portfolio for a web developer and visual designer.
The Ria Synergy Limited entry is presented as an independent website review,
not as work commissioned by or built for the company. The live site is
embedded in the project preview and can also be opened in a new tab.

## Run locally

Open `index.html` in a browser. The page has no build step or package
dependencies. Google Fonts are loaded over the network; system fallbacks are
included.

## Before publishing

- Review the role description and add any specific experience or project
  details you want highlighted from your resume.
